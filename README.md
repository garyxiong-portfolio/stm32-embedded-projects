# STM32 Sensor and Actuator Interfacing

Embedded C firmware by Gary Xiong for the STM32 NUCLEO-F401RE. The projects implement PWM output control, analog sampling, interrupt-based pulse measurement, and a buffered interface to a two-digit display using STM32 HAL and direct timer-register updates.

[Watch the hardware demonstration](https://youtu.be/6bkYGORAIQM)

## Demonstrated functions

The projects below follow the demonstration video's order and use the same names as the engineering portfolio. Each folder is a separate firmware build for the NUCLEO-F401RE; select and program one project at a time.

| Project | Implementation |
| --- | --- |
| [PWM brightness control](PWM_Brightness_Control) | Ramp TIM2 PWM duty cycle to fade the onboard LED |
| [User controls and status indication](User_Controls_and_Status_Indication) | Read the active-low push button and light the onboard LED while it is held |
| [RGB output control](RGB_Output_Control) | Cycle buffered GPIO outputs through red, green, blue, and off |
| [Servo motor control](Servo_Motor_Control) | Sweep a 50 Hz PWM signal between 0.5 ms and 2.5 ms pulse widths |
| [Numeric display interface](Numeric_Display_Interface) | Send a 0-99 count to the timer PCB as two four-bit BCD values |
| [Analog input acquisition](Analog_Input_Acquisition) | Sample ADC1 channel 9 at eight-bit resolution and report readings over UART |
| [Motor drive and rotation sensing](Motor_Drive_and_Rotation_Sensing) | Drive an L9110 with TIM4 PWM and count optical sensor pulses using GPIO interrupts |
| [Ultrasonic ranging](Ultrasonic_Ranging) | Capture both HC-SR04 echo edges using TIM3 and convert pulse width to distance |

## Timer board integration

The numeric display project reuses an assembled digital timer PCB as an MCU-controlled output. Eight GPIO signals pass through voltage-translation buffers to the board's BCD inputs. With the board powered at 5 V and held in LOAD mode, its existing decoder circuitry displays the tens and ones digits generated by the STM32. The count advances every 500 ms and wraps after 99.

## Open and build

1. Open STM32CubeIDE and choose **File > Import > General > Existing Projects into Workspace**.
2. Select this repository as the root directory and import the desired projects.
3. Build the selected project's **Debug** configuration, then connect the NUCLEO-F401RE through ST-LINK and create a debug configuration to program it.
4. For the acquisition and sensing projects, open the board's serial port at **115200 baud, 8 data bits, no parity, 1 stop bit, and no flow control**.

The saved projects use STM32CubeIDE 1.19.0 and STM32CubeF4 firmware V1.28.3. Each folder includes its `.ioc`, Eclipse project settings, application code, startup code, linker scripts, and vendor drivers. Pin assignments and operating details are documented in each project's README.

Open the `.ioc` to inspect peripheral settings. Application routines also configure timer registers directly, so the checked-in C sources define the complete behavior. Build the included source directly; automatic code regeneration may replace manual changes outside CubeMX preservation blocks.

Debug/Release outputs, workspace caches, and machine-specific launch files are excluded.

## Implementation notes

- The projects are independent demonstrations and reuse some peripherals and pins. They are not a single combined firmware image.
- The motor sensing program reports an accumulated optical pulse count. It does not calculate RPM or close a speed-control loop.
- The ultrasonic program uses a calibrated software trigger pulse and waits for both echo edges without a timeout. Its timing assumes the saved 16 MHz clock and Debug build settings.
